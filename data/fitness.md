## 填写说明

- 日期按北京时间填写，格式为 `YYYY-MM-DD`，可补填过去日期。
- 训练项目自由填写，例如力量训练、跑步、骑行、游泳、拉伸。
- 时长填写 `1` 到 `1440` 的整数，单位为分钟；备注可以留空。
- 同一天的多条记录会累计时长。修改一行可更正，删除一行可取消打卡。
- 只编辑上方表格，保留表头和两行 HTML 标记；备注中的竖线写成 `\|`。
- 提交后等待 GitHub Actions 部署完成，再打开主页查看。

下面只是填写示例，不会计入日历。将需要的行复制到上方表格并改成自己的实际记录：

```markdown
| 2026-10-10 | 力量训练 | 45 | 胸部、三头肌 |
| 2026-10-10 | 跑步 | 20 | 轻松跑 |
| 2026-10-09 | 拉伸 | 15 | |
```

`fitness.json` 是自动生成的日历数据，请通过本文件维护记录。
